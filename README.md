### E-Cart Python Django Platform

A full-featured, modern E-commerce web application designed to deliver an intuitive digital shopping experience. Built using Python, Django, HTML5, CSS3, and Bootstrap, this system features product catalogs, structured cart management, dynamic checkout handling, and localized data persistence. 

### 🚀 Key Features

* **User Account Ecosystem**: Secure enrollment, authentication, and personalized user profiles.
* **Product Catalog & Details**: Dynamic showcase filters sorting products by categories, tags, and stock.
* **Interactive Shopping Cart**: Add, adjust, update, or remove items instantaneously with automated tally calculation.
* **Clean Checkout Operations**: Simplified layout handling simulation for order submission tracking.
* **Media File Integration**: Clean asset handling directories for managing item product imagery.

### 🛠️ Tech Stack & Dependencies

* **Core Backend Architecture**: Python 3, Django Framework
* **User Interface Presentation**: HTML5, CSS3, Bootstrap Elements
* **Local Storage Layer**: SQLite Datastore Engine (db.sqlite3)

### 📦 Local Installation & Deployment

1. **Clone your personal repository branch:** 

git clone https://github.com/rathodgaurav207-lgtm/E-Cart-Python.git
cd E-Cart-Python

2. **Establish your Python virtual environment:** 

python -m venv venv
.\venv\Scripts\activate

3. **Install application dependencies:** 


pip install django pillow

4. **Synchronize database structures:** 


python manage.py migrate

5. **Fire up the web application runtime:** 


python manage.py runserver
